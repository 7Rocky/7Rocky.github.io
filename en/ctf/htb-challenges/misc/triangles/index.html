Source code analysis

As can be seen, secret.py uses a initial 2D-grid (grid.csv) and associates flag characters to coordinates within the grid. The flag shown in the given secret.py is just a placeholder, to understand the purpose of the script.

The main function in triangulate.py calls createTriangulation:

def createTriangulation():
    with open("out1.csv",'w') as out:
        writer = csv.writer(out)
        for coord in getFlagLocation():
            for val, dist in createCoords(coord[0],coord[1]):
                writer.writerow([val,dist])

def main():

As can be seen, for each coordinate that comes from getFlagLocation (from secret.py), some lines are written to out.csv. These lines come from createCoords:

In math terms, this function receives the coordinates of a flag character as $F = (x, y)$. It starts by generating three random points: $R_1 = (x_1, y_1)$, $R_2 = (x_2, y_2)$, $R_3 = (x_3, y_3)$. Those points are added to the flag coordinates:

$$ P_i = R_i + F = (x_i + x, y_i + y) \quad \forall i \in \{1, 2, 3\} $$

Note that cap only limits the upper and lower limit within the grid:

def cap(num):
    if num > 99:
        return 99
    if num < 0:
        return 0
    return num

Next, val1, val2 and val3 are the characters that appear at coordinates $P_1$, $P_2$ and $P_3$, respectively, in the grid.

The function returns 6 tuples:

  • val1 and $D\big(F, P_1\big)$
  • val2 and $D\big(F, P_2\big)$
  • val3 and $D\big(F, P_3\big)$
  • val1, val2 and $D\big(P_1, P_2\big)$
  • val2, val3 and $D\big(P_2, P_3\big)$
  • val1, val3 and $D\big(P_1, P_3\big)$

Where $D$ represents the euclidean distance:

$$ D\big((a_1, b_1), (a_2, b_2)\big) = \sqrt{(a_1 - a_2)^2 + (b_1 - b_2)^2} $$

def getDistance(x,y,x2,y2):
    return math.sqrt(math.pow(x - x2,2) + math.pow(y - y2,2))

Solution

Let’s name some results:

  • $d_1 = D\big(F, P_1\big)$
  • $d_2 = D\big(F, P_2\big)$
  • $d_3 = D\big(F, P_3\big)$
  • $d_{12} = D\big(P_1, P_2\big)$
  • $d_{23} = D\big(P_2, P_3\big)$
  • $d_{31} = D\big(P_1, P_3\big) = D\big(P_3, P_1\big)$

Now, let’s draw an example:

Using only the distances, we are not able to locate the coordinates of the point $F$, we will need the three points $P_1$, $P_2$ or $P_3$. If we had a single point $P_1$, we can ensure that $F$ lies in a circumference of radious $d_1$ and center $P_1$. If we have also $P_2$, we know that $F$ lies in the intersection of circumferences of radious $d_1$ and $d_2$ and centers $P_1$ and $P_2$, respectively. However, there are two intersections, so we need a third point $P_3$ to ensure a single point to locate $F$.

In order to find suitable $P_1$ and $P_2$ and $P_3$, we can try several points within the grid and test if they result in distances $d_1$, $d_2$ and $d_3$. Notice that we are given val1, val2 and val3, so we can take a few candidates for $P_1$, $P_2$ and $P_3$ and test them.

Implementation

Let’s start wrinting the solution in a Python script. First of all, let’s read the CSV files and define the dictionary of values and coordinates that hold such values:

#!/usr/bin/env python3

import csv

from collections import defaultdict
from itertools import product


with open('grid.csv') as f_grid, open('out.csv') as f_out:
    grid = [row for row in csv.reader(f_grid)]
    results = f_out.read().splitlines()

values = defaultdict(list)

for x, row in enumerate(grid):
    for y, value in enumerate(row):
        values[value].append(x + 1j * y)

When dealing with 2D coordinates in Python (and Go), I like to use complex numbers, because it is easier to operate with them. For instance, the euclidean distance $D$ between two points is simply the absolute value of the difference of two complex numbers:

$$ \begin{align*} |z_1 - z_2| & = |(a_1 + \mathrm{i} \; b_1) - (a_2 + \mathrm{i} \; b_2)| \\ & = |(a_1 - a_2) + \mathrm{i} \; (b_1 - b_2)| \\ & = \sqrt{(a_1 - a_2)^2 + (b_1 - b_2)^2} \\ & = D\big((a_1, b_1), (a_2, b_2)\big) \end{align*} $$

Now, for every sequence of 6 lines in out.csv (results), we will take val1, val2, val3 and the distances $d_1$, $d_2$, $d_3$, $d_{12}$, $d_{23}$ and $d_{31}$:

for i in range(0, len(results), 6):
    val1, d1 = results[i + 0][:1], float(results[i + 0][2:])
    val2, d2 = results[i + 1][:1], float(results[i + 1][2:])
    val3, d3 = results[i + 2][:1], float(results[i + 2][2:])

    d12 = float(results[i + 3][3:])
    d23 = float(results[i + 4][3:])
    d31 = float(results[i + 5][3:])

First of all, we find points $P_1$, $P_2$, and $P_3$ by considering all combinations of points that hold val1, val2 and val3, and we find the one that has distances $d_{12}$, $d_{23}$ and $d_{31}$:

    for P1, P2, P3 in product(values[val1], values[val2], values[val3]):
        if abs(P1 - P2) == d12 and abs(P2 - P3) == d23 and abs(P3 - P1) == d31:
            break

Once those points are found, we iterate through all points in the grid (itererating the dictionary) and print the value of the point $F$ that has distances $d_1$, $d_2$ and $d_3$ to points $P_1$, $P_2$ and $P_3$, respectively:

    for value, points in values.items():
        for F in points:
            if abs(F - P1) == d1 and abs(F - P2) == d2 and abs(F - P3) == d3:
                print(value, end='')
                break
