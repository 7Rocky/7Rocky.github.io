Contexto de RSA

También se nos proporciona el código fuente para generar esta salida. Ahí, podemos ver que $x = p + q$, $n = p q$ y $c$ es el texto cifrado. El exponente $e = 65537$.

RSA funciona de manera que, dado un mensaje $m$ en formato decimal, podemos cifrarlo como sigue:

$$ c = m^e \mod{n} $$

Y para descifrar, se necesitan dos valores más: $\phi(n) = (p - 1) (q - 1)$ y $d = e^{-1} \mod{\phi(n)}$, de manera que:

$$ m = c^d \mod{n} $$

Vulnerabilidad

Nótese que

$$ \phi(n) = (p - 1) (q - 1) = p q - p - q + 1 = n - (p + q) + 1 = n - x + 1 $$

Tenemos todo lo necesario para descifrar el mensaje. Este es un script en Python que realiza el descifrado:
